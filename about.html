THE IDEA BEHIND THE JOURNEY

Small plans. Memorable journeys.

Explore Ghana is a student travel website created by Eyram Fenu for the Web Technologies synthesis project.

Why Explore Ghana?

This project brings destination ideas, experiences and a simple planning tool together in one connected website.

Its five pages use HTML for structure, a shared CSS file for presentation and a small JavaScript function for calculating a trip budget.

Common questions

Can I book a trip here?

This is an educational project. It does not process bookings or payments.

Are the calculator values live prices?

No. They are editable example values for practising a budget calculation.

Contact form demonstration

This form demonstrates labels and browser validation. It does not send or save messages.
